# Live Airspace

A radar-style live traffic display for Apple TV, plus a macOS screen saver that hosts the same view.

## What it does
- **Cross-checks three independent feeds** (adsb.lol, adsb.fi, OpenSky). Reports are matched by ICAO hex, dead-reckoned to
  the same instant and compared. Aircraft confirmed by 2+ sources get a ring; with three sources a lone dissenter is
  identified and set aside; sources that disagree by more than 2 nm are drawn red and dashed; disagreeing altitudes show `?`.
- **Learns which source to trust**: each source's record of being the odd one out is shown beside it, and breaks ties
  when only two sources disagree.
- **Says when feeds are down** (per-source reason, "Reduced cross-checking", "NO LIVE DATA").
- **Details for the selected aircraft**: airline, route, type, registration, photo (adsbdb.com), with the route drawn on the radar.
- **Dark map underneath** (MapKit), airport markers (OurAirports), non-overlapping labels, altitude legend, fade-in.
- **Watch rules**: a banner when a chosen airline, type or registration enters range.
- **Ambient care**: slow drift, map "breathing", idle timer off, for OLED/plasma panels.

## Apple TV controls
| Remote | Action |
|---|---|
| Left / Right | Step through aircraft (nearest first) |
| Up / Down | Zoom range in / out |
| Play/Pause | Cycle location: Near me, then each airport preset |
| Select (click) | Settings (location, range, map, labels, units, watch list) |

## Layout
| Piece | What it is |
|---|---|
| `Sources/LiveAirspaceKit` | Models, feed parsers, merger, polling store, enrichment, airports, watch rules (no UI) |
| `Sources/LiveAirspaceUI` | SwiftUI `LiveAirspaceView`, settings, model; shared by tvOS and macOS |
| `LiveAirspaceTV` | tvOS app |
| `LiveAirspaceTopShelf` | tvOS Top Shelf extension: aircraft overhead, with photos |
| `LiveAirspaceSaver` | macOS `.saver` bundle (settings sheet: airport/custom coordinates, map, units, watch list) |
| `Sources/airspace-probe` | CLI: `airspace-probe` prints cross-check stats; `--place "London LHR"`; `--snapshot out.png` renders the view |

`LiveAirspace.xcodeproj` is generated by `Tools/make_xcodeproj.py`. `Tools/make_airports.py` rebuilds the airport table from OurAirports.

## Building
1. Open `LiveAirspace.xcodeproj` (generated by `Tools/make_xcodeproj.py`; Xcode 26 or later, tvOS 17+ / macOS 14+).
2. Set your own Apple developer team: `cp Config/Local.xcconfig.example Config/Local.xcconfig` and put your team ID in it
   (the file is gitignored). Bundle IDs are `com.bureau.liveairspace*`; change them in the generator if you need your own.
3. Run the **Live Airspace (tvOS)** scheme on an Apple TV or the tvOS simulator, or build **Live Airspace (Screen Saver)** for macOS.

## OpenSky account (optional, entered in the app)
Anonymous OpenSky allows ~400 requests/day (polled every 4 min). With your own API client it allows ~4,000/day (polled every 30 s).
1. Create an API client in your OpenSky account.
2. In the app: **Select → Settings → OpenSky account**, enter the client ID and secret, and choose **Check and save**.

The app verifies the client with OpenSky, then keeps it in the device keychain. Nothing is stored in the app bundle or this repository.
For command-line testing, `airspace-probe` reads `OPENSKY_CLIENT_ID` and `OPENSKY_CLIENT_SECRET` from the environment.

## Notes
- tvOS has no third-party screen saver API. The tvOS app's ambient mode is the substitute; the Mac `.saver` is a real screen saver.
- adsb.lol is limited to about 10 requests/min (polled every 10 s); adsb.fi every 5 s. Rate-limit replies are honoured via Retry-After.
- The Mac saver can't show a location prompt, so it has no "Near me"; pick an airport or enter coordinates.
- Top Shelf passes the current airspace to the extension through a shared keychain group (App Groups need explicit portal registration).
- Free community feeds, no SLA. Not for navigation.
- Run tests with `swift test`. If the project lives in an iCloud-synced folder and codesigning fails on the test bundle, add `--scratch-path /tmp/spm`.
